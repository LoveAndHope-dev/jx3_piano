# 向导缩进与复选框点击修复

## Why

- 向导中「铺面编辑工具栏」与「钢琴窗」的说明紧贴左边，与所属的正常模式小节缺少层级感。
- 播放列表行前的自绘复选框为了隐藏原生指示器，把 indicator 尺寸设为 0；QCheckBox 的点击命中区域随之变成空区域，点击复选框没有任何反应。

## What Changes

- **向导缩进**：「铺面编辑工具栏」与「钢琴窗」小节中的每一行说明整体左缩进，层级与正常模式一致。
- **复选框点击**：自绘复选框的可点击区域覆盖整个控件；点击复选框内任意位置都能切换勾选状态，并保持原有的批量选择行为。

## 非目标

- 不改变复选框的自绘外观、主题颜色或列表行布局。
- 不改变勾选集合、全选、批量删除或刷新后保留勾选的逻辑。
- 不改变向导的文字内容与分区结构。
