# Spec Delta：页面头部

## Purpose

页面内容只保留操作控件，不重复标签页名称。

## ADDED Requirements

### Requirement: 页内不重复标签页标题

铺面编辑页与操作日志页 SHALL NOT 在页面内再次显示「铺面编辑」「操作日志」标题标签；标题信息只由标签页名称承担。

#### Scenario: 铺面编辑页

- **WHEN** 打开「🎼 铺面编辑」标签页
- **THEN** 第一行只有右侧的「演奏模式 / 编辑模式」切换，没有页内大标题

#### Scenario: 操作日志页

- **WHEN** 打开「📋 操作日志」标签页
- **THEN** 头部只有右侧「清空」按钮，没有页内标题
