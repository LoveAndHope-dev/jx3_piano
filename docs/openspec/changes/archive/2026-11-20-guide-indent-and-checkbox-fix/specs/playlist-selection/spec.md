# Spec Delta：复选框点击区域

## MODIFIED Requirements

### Requirement: 多选与全选

播放列表每行 SHALL 在名称前提供复选框。点击行本身 MUST 只切换当前曲目（单选并加载铺面），MUST NOT 因 Ctrl/Shift 点击产生多选。只有点击复选框才改变批量选择状态；复选框的可点击区域 MUST 覆盖整个复选框控件，点击其内部任意位置都能切换勾选状态。界面 SHALL 提供「全选」操作，勾选当前过滤结果中的全部曲目。刷新或搜索后，仍然存在的曲目 SHALL 保留原勾选状态。

#### Scenario: 点击行只单选

- **WHEN** 依次点击三个曲目行
- **THEN** 每次都只有当前行被选中并加载，其他行的勾选状态不变

#### Scenario: Ctrl 多选

- **WHEN** 按住 Ctrl 点击曲目行
- **THEN** 仍然只是单选该行，不产生多选，也不改变任何行的勾选状态

#### Scenario: 勾选多行

- **WHEN** 点击三个曲目行前的复选框
- **THEN** 三行被勾选，但当前曲目仍是最后点击的行

#### Scenario: 点击复选框任意位置

- **WHEN** 点击复选框内的边框或中心位置
- **THEN** 勾选状态都切换一次，当前曲目不变

#### Scenario: 全选

- **WHEN** 点击「全选」
- **THEN** 列表中当前显示的所有曲目都被勾选

#### Scenario: 搜索后保留勾选

- **WHEN** 勾选若干曲目后修改搜索词再清除
- **THEN** 仍然存在的曲目保持勾选
