# 播放列表多选删除与音域配色对比

## Why

- 播放列表每行一个删除按钮，只能逐条删；整理导入的曲目时需要重复确认很多次。
- 音符的灰色仍按固定游戏键位集合决定，而背景淡色区域已经跟随黄框，两者语义不一致。
- 黄框内外的背景底色差异太小，难以一眼看出音域范围。

## What Changes

- **播放列表多选删除**：列表支持 Ctrl/Shift 多选，新增「全选」与「删除选中」操作；删除前一次性确认，选中的曲目连同 `edited` MIDI 与 play_code 一起清理；删除当前曲目时清空铺面。
- **移除行内删除按钮**，避免与多选操作重复。
- **音符灰色跟随音域框**：音高在黄色框体范围（上下各 1 半音）内保持正常颜色，超出上/下界的音符变灰；框体移动或映射变化时即时刷新。
- **加大背景对比**：黄框内保持现有底色，框外明显加深，使音域边界更清晰。

## 非目标

- 不改变选择曲目时的铺面加载逻辑（仍以当前项为准）。
- 不改变音符正常颜色的含义（仍区分选中/未选中）。
- 不调整播放列表排序、搜索与导入流程。
