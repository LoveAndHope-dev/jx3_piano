# 播放前确保 play_code 与当前铺面一致

## Why

`play_code` JSON 目前只在加载曲目、进入演奏模式或文件缺失时生成。若在演奏模式里拖动黄框或改 BPM，点击「演奏」仍读取旧 JSON，导致实际按键范围/速度与界面不一致。

## What Changes

- 在 GUI 维护「播放资产是否过期」标记：音符变化（含 BPM 缩放）、黄色音域框变化、移调变化、曲目切换时置为过期。
- 点击「演奏」前检查：过期或 JSON 缺失时，先用当前音符、BPM、黄框与移调重新生成 `midi/edited/<曲目>.mid` 与 `play_code/<曲目>.json`，然后播放；未过期时直接复用，避免重复写盘。
- 进入演奏模式时的自动保存保留，作为外部工具可用性与兜底。

## 非目标

- 不改变按键映射、时间轴与播放调度。
- 不在每次编辑时立即写盘（仍由进入演奏模式 / 点击演奏触发）。
- 不改变 JSON 结构。
