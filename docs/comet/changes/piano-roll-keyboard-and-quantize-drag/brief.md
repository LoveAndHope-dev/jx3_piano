# Outcome

铺面编辑视图（`piano_roll.py` 的 `PianoRollWidget`）在现有的音符新增/拖动/调整时长/删除、乐器音域框拖动能力之上，新增四项让它更接近传统 DAW 钢琴卷帘的能力：

- **左侧钢琴键盘**：画出真实的黑白键形状，固定贴在视图左边缘，作为纯视觉音高参照。
- **量化拖动**：新增一个量化步长下拉框（关闭/1/2~1/128），开启后拖动音符改变起始时间、拖动右边缘改变时长都会吸附到对应的节拍网格。
- **多选整体拖动**：支持 Ctrl+A 全选、矩形框选、Ctrl/Shift+单击多选，选中多个音符后可以整体左右（时间）/上下（音高）拖动，相对关系保持不变；Delete 删除全部选中音符。
- **小节网格线**：按曲目的拍号（优先读取 MIDI 自带 `time_signature`，没有则默认 4/4）与已有的 tempo(BPM) 换算，在铺面背景上叠加比现有逐秒参考线更明显的小节线。

播放线（`set_playhead` 驱动的播放进度线）现状已经正确工作，本次改动不涉及其实现，只作为回归验证项保留。

# Scope

1. **钢琴键盘**
   - 视图左边缘新增一条竖直排列的钢琴键盘，覆盖铺面全部 88 个 MIDI 音高行（108→21，与现有行一一对齐、同一行高）；黑键（相对 C 偏移在 `{1,3,6,8,10}`）与白键用真实的键形区分（例如白键为通栏矩形、黑键为叠加在白键上偏一侧的较窄矩形），不仅仅是颜色深浅。
   - 键盘固定贴在视图左边缘：随铺面纵向（音高方向）滚动一起滚动，但不随铺面横向（时间轴方向）滚动移动，本身不占用/不移动铺面时间轴 0 点的位置。
   - 键盘是纯视觉图层：不接受、不拦截任何鼠标事件，点击/悬停在键盘上没有任何反应（不发声、不模拟按键、不改变铺面状态），也不影响铺面原有的音符/音域框命中判定。

2. **量化拖动**
   - 在音域框工具栏新增一个量化步长下拉框，选项为「关闭」（默认）、`1/2`、`1/4`、`1/8`、`1/16`、`1/32`、`1/64`、`1/128`；这些分数是传统音符时值命名（相对全音符），其中 `1/4` 固定等于一拍，只由 tempo(BPM) 决定网格的绝对秒数，不依赖拍号。
   - 选中「关闭」以外的档位时：拖动音符改变起始时间，松开后新的起始时间吸附到从时间 0 起的最近网格点；拖动音符右边缘调整时长，松开后新的结束时间（起始时间+时长）同样吸附到最近网格点，时长仍不小于既有的最小时长限制。
   - 选中「关闭」时，拖动行为与本次改动前完全一致，不做任何吸附。

3. **多选与整体拖动**
   - 铺面获得焦点时按 Ctrl+A：选中当前铺面上的全部音符。
   - 在铺面空白处（非音符、非音域框内部）按下并拖出一个矩形后释放：选中与该矩形有任意重叠的全部音符，替换之前的选择。
   - 按住 Ctrl 或 Shift 后单击某个音符：切换这个音符的选中状态，不影响其余已选中音符；不按 Ctrl/Shift 直接单击音符：只选中这一个音符（与现有行为一致）。
   - 有多个音符处于选中状态时，从其中任意一个已选中音符的内部按下并拖动：全部选中的音符一起整体平移（横向=时间、纵向=音高），平移前后音符间的相对时间间隔与音高关系保持不变；若量化开启，只有被按下的这一个音符的新起始时间参与吸附计算，其余音符按同样的时间偏移量平移（不单独各自吸附）。
   - Delete/Backspace 删除当前全部选中的音符（原来只删除单个选中音符）。
   - 右键菜单行为不变：仍然只对被右键点击的这一个音符生效（弹出「删除音符」，只删除这一个音符），不因多选状态扩展为批量操作。

4. **小节网格线**
   - 加载曲目时读取该 MIDI 文件中第一个出现的 `time_signature` 元事件（numerator/denominator）；不存在该元事件时按 4/4 处理。
   - 复用已有的 tempo(BPM) 扫描逻辑，按拍号换算每小节的秒数（一拍秒数 = `60/BPM × 4/denominator`；每小节秒数 = 一拍秒数 × numerator），从时间 0 起每隔一个小节秒数在背景上画一条小节线，视觉上比现有逐秒参考线更明显（两者同时存在，互不替代）。
   - 切换曲目时按新曲目的拍号与 tempo 重新计算、重绘小节线。

5. **播放线（回归项，不新增行为）**
   - 播放线程运行期间，铺面播放线随实际播放进度持续更新的现状（`on_play_progress` → `set_playhead`）保持不变；本次改动不修改这部分实现。

# Non-goals

- 钢琴键盘不响应点击/悬停，不产生试音声音，也不发送任何真实按键模拟。
- 不新增拍号/BPM 的手动编辑 UI；拍号只读取自 MIDI 文件的 `time_signature` 元事件或默认 4/4，没有用户可调覆盖入口。
- 不扩展右键菜单为批量操作，不新增独立的"批量修改音符属性"面板。
- 不改变新建音符（点击铺面空白处新增音符）的默认时长、默认音高判定等既有行为。
- 不改变现有逐秒背景参考线的绘制逻辑，只叠加新的小节线。
- 不改变乐器音域框自身的拖动/跨度/移调播放逻辑（`range-box-full-keyboard-drag` change 的范围，本次不重新触碰）。
- 不新增撤销/重做。
- 不改变播放线 `set_playhead` 的现有实现，只做回归验证。

# Acceptance examples

- A1: 铺面编辑 Tab 加载任意曲目后，视图左侧显示一条竖直钢琴键盘，88 行从上到下依次对应 MIDI 108(C8) 到 21(A0)；黑键（相对 C 偏移在 `{1,3,6,8,10}`）与白键有明显不同的键形/颜色区分；点击键盘上任意位置不触发任何声音、按键模拟或铺面状态变化。
- A2: 水平拖动铺面视图（滚动到曲目中段）后，钢琴键盘仍然贴在视图左边缘、不随时间轴滚动移出可见区域；纵向滚动铺面时，键盘与铺面的音高行始终保持对齐。
- A3: 量化下拉框默认选中「关闭」；此时拖动音符改变起始时间、拖动右边缘改变时长，新的时间值不做任何网格吸附，与本次改动前完全一致。
- A4: 把量化改为「1/4」，曲目 tempo 为 120 BPM（一拍=0.5秒，四分音符网格间距=0.5秒）：拖动一个音符改变起始时间，松开后该音符的起始时间总是 0.5 秒的整数倍。
- A5: 在 A4 的量化设置下，拖动某个音符的右边缘调整时长，松开后该音符的结束时间同样吸附到最近的 0.5 秒网格点，且时长不小于既有的最小时长限制。
- A6: 把量化改为「1/8」（同一首 120 BPM 曲目），网格间距变为 0.25 秒；拖动音符起始时间吸附到最近的 0.25 秒网格点。
- A7: 铺面获得焦点时按 Ctrl+A：铺面上全部音符同时进入选中状态。
- A8: 在铺面空白处按下并拖出一个矩形后释放：矩形范围内、或与矩形有任意重叠的全部音符进入选中状态，替换之前的选择。
- A9: 先选中 3 个以上音符，按住 Ctrl 单击其中一个已选中的音符：这个音符变为未选中，其余选中状态不变；再按住 Ctrl 单击一个原本未选中的音符：这个音符加入选中集合，其余不变。
- A10: 有多个音符处于选中状态时，从其中任意一个选中音符内部按下并整体拖动：全部选中音符一起平移相同的时间偏移量与相同的半音偏移量，平移前后音符间的相对时间间隔和音高关系保持不变。
- A11: 在 A10 的场景下若量化不是「关闭」：拖动结束后，被按下的那一个音符的新起始时间吸附到最近网格点；其余被一起平移的音符按同样的时间偏移量移动，不单独各自吸附。
- A12: 有多个音符处于选中状态时按 Delete/Backspace：全部选中音符同时被删除；只有一个音符被选中时按 Delete/Backspace 的既有行为不变（只删这一个）。
- A13: 有多个音符处于选中状态时，右键点击其中一个音符：只弹出针对这一个被点击音符的「删除音符」菜单项，执行后只有这一个音符被删除，其余原本选中的音符不受影响。
- A14: 加载一个 MIDI 文件中带 `time_signature` 元事件（例如 3/4 拍）的曲目：铺面背景每隔"3 拍对应的秒数"画一条小节线，比现有逐秒参考线视觉上更明显。
- A15: 加载一个不带 `time_signature` 元事件的曲目：铺面按 4/4 默认值画小节线（每 4 拍对应的秒数画一条）。
- A16: 切换到另一首拍号或 tempo 不同的曲目：小节线按新曲目的拍号与 tempo 重新计算位置，不沿用上一首曲目的间距。
- A17: 点击播放开始后，铺面播放线随实际播放进度持续右移；播放结束或停止后播放线消失；这部分行为与本次改动前完全一致（回归验证项）。

# Constraints and invariants

- 量化的「1/N」含义固定为传统音符时值命名，`1/4` 恒等于一拍；网格的绝对时长只由 tempo(BPM) 决定，拍号只用于小节线间距，不影响量化网格间距。
- 拖动的量化吸附只影响"新的起始时间"和"新的结束时间（时长）"这两个值本身，不改变既有的最小时长限制、音高钳制范围、只读态（播放期间禁用编辑）等既有约束。
- 多选整体拖动时，只有被按下的锚点音符的新位置参与量化吸附计算；其余音符严格按相同的（时间, 音高）偏移量平移，保证音符间的相对节奏和音程关系在吸附前后都不变。
- 钢琴键盘、小节线都是纯视觉/背景图元，不接受鼠标事件，不参与音符、音域框的命中测试，不改变已有图元的 Z 顺序语义（背景在音符之下、播放线在音符之上等既有层次不变）。
- 拍号解析失败、缺失或格式异常时必须回退到 4/4，不得抛出异常或阻塞铺面加载。
- 小节线与现有逐秒参考线同时存在，互不替代、互不删除。

# Decisions

- 小节网格线的拍号：优先读取 MIDI 文件中的 `time_signature` 元事件；不存在时默认 4/4。（用户已确认）
- 量化吸附同时作用于「拖动改变起始时间」和「拖动右边缘改变时长」两个操作；额外提供「关闭」档位并作为默认值，选择关闭时行为与当前完全一致。（用户已确认）
- 「全选拖动」实现为 Ctrl+A 全选 + 通用多选（矩形框选空白区域、Ctrl/Shift+单击逐个切换选中状态），选中多个音符后可整体拖动。（用户已确认）
- 钢琴键盘画出后纯视觉参考，点击/悬停无任何反应，不产生声音或按键模拟。（用户已确认）
- 钢琴键盘固定贴在视图左边缘，随铺面纵向滚动、不随铺面横向（时间轴）滚动移动——这是常规钢琴卷帘惯例的默认实现选择，未单独征询用户，已在 Shape 确认摘要中向用户说明。
- 量化的「1/N」是传统音符时值命名（`1/4`=一拍），只依赖 tempo(BPM)，不依赖拍号；拍号只用于计算小节线间距——这两套换算彼此独立。
- 多选整体拖动时的量化吸附只以被按下的锚点音符为基准计算偏移量，其余选中音符按相同偏移量平移，不单独各自吸附。
- 右键菜单继续只对被点击的单个音符生效，不扩展为批量操作。
