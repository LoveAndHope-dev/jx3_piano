# 修复播放起点与辅助线不同步

## 问题

从铺面中间位置开始播放时，DD 按键会比 MIDI 窗体里的播放辅助线提前触发；提前量等于起播点所在延时段的剩余时长，并在整首播放期间保持不变。

## 根因

`play_assets.split_playback_at()` 在起播点落在一个延时中间时，把**整段延时丢弃**，而不是保留剩余部分：

```python
data = [1.0, 'Q', 1.0, 'W', 2.0, 'E']  # 按键位于 0s / 1s / 3s
split_playback_at(data, 2.6)  # 实际 ['E']，应为 [1.4, 'E']
```

辅助线按 `起播点 + 实际耗时` 推进，而按键序列少等了残余延时，于是画面与声音错开。

## 修复范围

- 只改 `split_playback_at`：穿越延时边界时，把剩余延时放回序列开头，再返回其后的按键与延时。
- 更新 `tests/test_play_assets.py` 中把错误行为写成期望的用例，并补充边界用例。

## 非目标

- 不改变 play_code JSON 结构、按键映射、时间轴生成与播放线程逻辑。
- 不改变辅助线推进方式或播放界面行为。
