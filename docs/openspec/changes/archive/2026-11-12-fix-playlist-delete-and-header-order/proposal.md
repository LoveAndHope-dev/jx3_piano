# 播放列表行修正与工具栏换位

## Why

播放列表的行控件与条目文字同时显示导致曲目名重影；删除仅写隐藏记录、`midi/` 里导入的副本仍在，用户希望删除时同时清理工具内的副本；工具栏顶部按钮与标题的位置也需要按使用频率调整。

## What Changes

- 播放列表每一行只显示一次曲目名（行控件负责显示，条目文字不再重复绘制）。
- 删除曲目时直接删除 `midi/` 下由导入生成的副本文件（不删除用户最初选择的源文件），再清理当前曲目的铺面/播放/BPM 缓存；取消时不删除。
- 工具栏位置调整：标题「铺面编辑」移到上方动作行；「弹奏」与「曲谱优化」对调，使「弹奏」位于工具栏最前、曲谱优化紧随其后。
- 不再使用隐藏记录与「恢复所有已移除曲目」入口（曲目已被真正删除）。

## Impact

- `gui.py`：列表行控件与条目文字、删除逻辑、工具栏排列、移除恢复菜单。
- `playlist_store.py`：目录枚举仍保留；隐藏记录函数不再被主流程使用（保留导出以避免破坏旧数据）。
- 更新 `playlist-management` 与 `piano-roll-toolbar-layout` 的 delta spec。
