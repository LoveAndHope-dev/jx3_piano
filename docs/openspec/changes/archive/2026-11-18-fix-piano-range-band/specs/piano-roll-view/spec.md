# Spec Delta：钢琴窗音域背景

## Purpose

让铺面背景的高亮区域与乐器音域框保持一致，并随框体移动即时更新。

## ADDED Requirements

### Requirement: 背景淡色区域跟随音域框

钢琴窗背景行的淡/暗 SHALL 由当前黄色音域框范围决定：框体上下边界各扩展 1 个半音内的行使用正常底色，其余行使用更暗底色。音域框拖动或最低/最高键位映射变化时，背景 MUST 立即更新，不需要重新加载曲目。

#### Scenario: 编辑模式查看

- **WHEN** 打开一首曲目且未进入演奏模式
- **THEN** 背景淡色区域与当前音域框（默认 C2–B5 扩展 1 半音）一致

#### Scenario: 拖动音域框

- **WHEN** 在演奏模式拖动黄色音域框
- **THEN** 淡色区域随框体一起上下移动

#### Scenario: 修改键位映射

- **WHEN** 修改最低/最高键位映射下拉
- **THEN** 背景淡色区域按新的框体跨度更新
