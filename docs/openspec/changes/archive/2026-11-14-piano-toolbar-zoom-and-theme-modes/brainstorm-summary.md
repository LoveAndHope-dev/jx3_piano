# 设计探索摘要（Design）

change: `piano-toolbar-zoom-and-theme-modes`

## 已确认（用户）

- 合并按钮按模式切换功能：编辑=保存，演奏=播放/停止
- 第三行顺序：最低、最高、绝对最低、绝对最高
- 亮暗切换会话内记忆
- 纵向缩放以鼠标位置为锚点
- 左侧键盘已固定，只需保证/回归

## 现状事实

- 工具栏在 `app/ui/piano_page.py`，两行；`play_btn` 与 `piano_save_btn` 分离
- 播放/历史/列表页直接调用 `play_btn`/`piano_save_btn` 的文案与可用状态
- `ROW_HEIGHT` 是 `piano_roll/geometry.py` 常量，画布/绘制/键盘共用
- 键盘是画布左侧独立控件，纵向随滚动同步
- 主题令牌集中在 `app/ui/theme.py`，当前仅深色

## 候选方案

1. 工具栏三行：标题+模式按钮右侧；主按钮/优化靠左、量化/BPM 靠右；键位与音域靠左
2. 主按钮合并到 `self.play_btn`，新增 `_update_primary_btn()` 统一文案/可用态；`piano_save_btn` 退役
3. 行高改为画布实例状态（6–24px），`Shift+滚轮` 以鼠标音高为锚点缩放
4. 播放开始时 `focus_vertical_range_center()` 居中黄框；不持续强制
5. `DARK_TOKENS`/`LIGHT_TOKENS` + `apply_theme(mode)`，控制面板标题行加切换按钮

## 备选

| 备选 | 原因 |
| --- | --- |
| 保留两个按钮只换文案 | 与用户「合并为一个按键」不符 |
| 编辑模式点击保存后自动播放 | 用户选择按模式切换功能 |
| 持续强制纵向居中 | 会妨碍播放时查看其他音域 |
| 主题持久化/跟随系统 | 用户选择会话内记忆 |

## 风险

- 合并按钮改变播放入口（需先切演奏模式）
- 行高变化影响场景高度、背景、键盘与命中测试，需要统一入口
- 现有测试按旧按钮结构断言，需要更新
- 浅色主题下铺面画布语义色对比度
