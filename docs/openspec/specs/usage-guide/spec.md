# usage-guide Specification

## Purpose
提供一个集中、可滚动的功能说明，帮助新用户理解界面各区域的用途与快捷键。

## Requirements

### Requirement: 使用向导入口与内容

控制面板 SHALL 提供「❓ 向导」按钮，点击后打开非模态说明窗口，窗口 MUST 可滚动并覆盖：

- 控制面板各按钮（含简单模式、主题、置顶、向导同排）
- 播放列表的选择/勾选/全选/删除/搜索排序与悬停滚动
- 操作日志与常用快捷键
- 数据位置说明（保留工作目录与 play_code 位置）

向导 MUST 将「简单模式」与「正常模式」分成独立小节。简单模式说明隐藏铺面编辑、固定键位与一键优化播放；正常模式说明完整的编辑与播放流程。

「铺面编辑工具栏」与「钢琴窗」的说明 MUST 归入正常模式小节，不再作为独立顶层章节。

向导 MUST 包含乐器移调说明：朝晖琴、南音三弦等拨奏类乐器的移调建议在 +5 到 -5 之间。简单模式小节 MUST 说明 MIDI 中的所有音符需要落在 C2 至 B5 之间。

简单模式与正常模式小节 MUST 使用面向用户的描述，MUST NOT 出现「重读原始 MIDI」「保存 play_code JSON」「铺面资产」等内部实现术语。

#### Scenario: 打开向导

- **WHEN** 点击控制面板「❓ 向导」
- **THEN** 打开说明窗口并显示上述分区内容，可滚动阅读

#### Scenario: 简单/正常模式分开说明

- **WHEN** 阅读向导
- **THEN** 能看到独立的「简单模式」与「正常模式」小节，各自说明可用功能

#### Scenario: 编辑说明归入正常模式

- **WHEN** 阅读「正常模式」小节
- **THEN** 能看到铺面编辑工具栏与钢琴窗的说明

#### Scenario: 音域与移调说明

- **WHEN** 阅读向导
- **THEN** 简单模式能看到「音符需在 C2 至 B5 之间」，并能看到拨奏类乐器移调 +5 到 -5 的说明

#### Scenario: 关闭向导

- **WHEN** 点击窗口内「关闭」
- **THEN** 说明窗口关闭，主界面保持不变

### Requirement: 正常模式下的编辑说明缩进

「铺面编辑工具栏」与「钢琴窗」小节 SHALL 整体缩进：小节标题与其下每一行说明 MUST 使用相同的左缩进量，使这些内容在视觉上归属正常模式。

#### Scenario: 查看编辑说明

- **WHEN** 阅读正常模式下的铺面编辑工具栏或钢琴窗说明
- **THEN** 每行说明都带有一致的左缩进，不与小节标题齐平

#### Scenario: 标题与列表一起缩进

- **WHEN** 阅读「铺面编辑工具栏」或「钢琴窗」小节
- **THEN** 小节标题与列表项相对正常模式标题保持相同的左缩进
