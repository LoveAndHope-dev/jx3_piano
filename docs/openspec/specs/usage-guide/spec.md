# usage-guide Specification

## Purpose
提供一个集中、可滚动的功能说明，帮助新用户理解界面各区域的用途与快捷键。

## Requirements

### Requirement: 使用向导入口与内容

控制面板 SHALL 提供「❓ 向导」按钮，点击后打开非模态说明窗口，窗口 MUST 可滚动并覆盖：

- 控制面板各按钮
- 播放列表的选择/勾选/全选/删除/搜索排序
- 铺面编辑三行工具栏
- 钢琴窗的编辑、缩放、播放辅助线与音域框
- 操作日志与常用快捷键

#### Scenario: 打开向导

- **WHEN** 点击控制面板「❓ 向导」
- **THEN** 打开说明窗口并显示上述分区内容，可滚动阅读

#### Scenario: 关闭向导

- **WHEN** 点击窗口内「关闭」
- **THEN** 说明窗口关闭，主界面保持不变
