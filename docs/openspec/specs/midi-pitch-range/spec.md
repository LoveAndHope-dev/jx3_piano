# midi-pitch-range Specification

## Purpose
导入的 MIDI 音高 0–127 必须能完整显示、编辑与写回，不能再因移调越界而报错。

## Requirements

### Requirement: 导入移调不越界

自动移调 SHALL 只选择让全部音符仍处于 MIDI 0–127 的候选；构建音符条目时 MUST 把越界音高钳制到 0–127；写回 MIDI 时 MUST 跳过任何仍越界的音符并记录警告，不得把越界值交给 mido。

#### Scenario: 移调会推高音符

- **WHEN** 曲目含大量 24–71 的音符并夹有一个 120
- **THEN** 自动移调不会选择会让 120 超过 127 的值；导入与写回均成功

#### Scenario: 越界音符写回

- **WHEN** 音符列表中仍存在 <0 或 >127 的音高
- **THEN** 写回时跳过该音符并输出警告，不抛 `data byte must be in range 0..127`

### Requirement: 钢琴窗覆盖 0–127

钢琴窗 SHALL 支持 MIDI 音高 0–127：键盘、行高、音域框、拖动与键盘移调都以 0/127 为边界。导入的极低/极高音符 MUST 显示在各自音高行，并可上下移动；不得堆叠在边界行或被卡住。

#### Scenario: 极低与极高音符

- **WHEN** 导入包含 0、12、120、127 的曲目
- **THEN** 它们在铺面上分别占据不同的音高行，可正常选中并上下拖动

#### Scenario: 边界移调

- **WHEN** 选中 126、127 两个音符按 ↑
- **THEN** 整组保持不动（会越过 127），但单独选中 126 时可移到 127
