# Spec Delta

## Purpose

让用户在铺面编辑工具栏上，始终能看到黄色乐器音域框当前实际生效的最低/最高键对应的标准钢琴音名，而不必依赖可能与框体实际状态不同步的下拉框选择值。

## ADDED Requirements

### Requirement: 只读展示当前音域框的最低/最高键对应的钢琴音名
铺面编辑工具栏 SHALL 提供两个只读字段，分别展示黄色乐器音域框当前实际生效的最低键和最高键对应的标准钢琴音名（白键音名，如 `C4`），而不是「最低映射/最高映射」下拉框使用的游戏按键字母标签；用户不能直接编辑这两个字段的内容。

#### Scenario: 打开曲目后展示默认音域
- **WHEN** 用户在左侧播放列表选中一首曲目，铺面编辑区域加载该曲目并把乐器音域框重置为默认范围
- **THEN** 只读字段分别显示该默认范围的最低键和最高键对应的标准钢琴音名

#### Scenario: 拖动音域框后实时刷新
- **WHEN** 用户在铺面上直接拖动黄色乐器音域框，使其跨度覆盖的最低/最高键位发生变化
- **THEN** 只读字段随拖动同步刷新为框体当前实际覆盖的最低键和最高键对应的标准钢琴音名

#### Scenario: 下拉框联动调整跨度后展示实际生效边界
- **WHEN** 用户修改「最低映射」或「最高映射」下拉框，且新的跨度导致音域框的低边界被下压（不等于下拉框当前选中的值）
- **THEN** 只读字段显示音域框调整后实际生效的最低键和最高键对应的标准钢琴音名，而不是下拉框当前选中但未必生效的值

#### Scenario: 字段不可编辑
- **WHEN** 用户尝试向只读字段输入或修改内容
- **THEN** 字段内容保持不变，不接受用户的直接编辑
