# 钢琴窗淡色区域跟随土黄色音域框

## 问题

钢琴窗背景里有一块「淡色区域」，目前按固定的游戏键位映射集合（约 B1–C6，即音域框 ±1 半音）着色，不会随黄色音域框移动。用户希望它与编辑模式下看到的土黄色框体范围一致，并随框体移动。

## 根因

`_build_background` 用 `pitch not in self._mapped_pitches` 决定行底色；这个集合是固定的 28 键范围，与 `_range_low_pitch/_range_high_pitch` 无关，且框体移动后不重绘。

## 修复范围

- 背景行底色改为按当前音域框范围（上下各扩展 1 个半音，与框体视觉范围一致）决定淡/暗。
- 记录每一行的图元，音域框拖动或映射下拉改变时原地更新底色，不重建整个场景。
- 切换曲目、缩放、加载时沿用当前框体范围重绘。

## 非目标

- 不改变音符颜色（仍按是否可映射区分）。
- 不改变框体本身的位置、拖动手感与可见性规则。
