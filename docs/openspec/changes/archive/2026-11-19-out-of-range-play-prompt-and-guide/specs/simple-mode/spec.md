# Spec Delta：简单模式播放前确认

## MODIFIED Requirements

### Requirement: 简单模式一键播放

简单模式的「▶️ 播放」SHALL 依次执行：

1. 从当前曲目的原始 MIDI 重新读取音符；
2. 统计超出当前可演奏音域的音符；若数量大于 0，MUST 弹出确认框说明数量，并由用户选择继续播放或取消；取消时 MUST NOT 执行曲谱优化、保存或播放；
3. 对全部音符执行曲谱优化（1/32 拍琶音展开）；
4. 保存优化后的工作 MIDI 与 play_code JSON；
5. 读取 JSON 开始播放。

每次点击都从原始 MIDI 重新开始，重复点击不会叠加优化；播放过程中再次点击 MUST 不重启。

#### Scenario: 一键播放

- **WHEN** 选中曲目后在简单模式点击「▶️ 播放」
- **THEN** 先优化并保存，再开始播放，日志记录优化与保存

#### Scenario: 重复播放

- **WHEN** 播放结束后再次点击「▶️ 播放」
- **THEN** 从原始 MIDI 重新优化一次，结果与第一次相同

#### Scenario: 存在无法演奏的音符时取消

- **WHEN** 曲目包含超出可演奏音域的音符，用户在弹出的确认框中选择取消
- **THEN** 不执行优化、不保存、不开始播放，当前铺面保持原有内容
