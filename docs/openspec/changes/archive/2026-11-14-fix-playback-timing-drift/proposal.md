# 修复播放越播越偏（按键滞后）

## 问题

从任意位置播放时，DD 按键相对铺面播放辅助线逐渐滞后：越到后面偏差越大，从头播与中段起播都出现。上一轮修复解决的是起点裁剪丢延时（固定偏移），本次是随时间累积的漂移。

## 根因

`player._execute_playback_data()` 用相对延时推进：

```python
time.sleep(min(0.01, remaining_delay))   # 每 10ms 一步，单步必然略微超时
self.dd.key_press(key)                   # DD_key 按下/释放各一次调用，也有耗时
```

每一段的执行开销都会叠加到下一段，整首累计；而辅助线按 `time.time()` 的真实时间推进，于是按键越来越晚。

## 修复范围

- 改 `_execute_playback_data` 为绝对时间轴调度：用累计延时算出每组按键的应触发时刻，睡到该时刻再按键，使按键开销与 sleep 抖动不再累积。
- 播放进度回调仍按真实耗时上报，保证辅助线与声音同步。
- 新增可注入的时钟/按键器用于测试，不改变 `play_from_data` 的对外行为。

## 非目标

- 不改 play_code JSON 结构、按键映射、起点裁剪与界面。
- 不改变倒计时、停止逻辑与播放完成统计。
