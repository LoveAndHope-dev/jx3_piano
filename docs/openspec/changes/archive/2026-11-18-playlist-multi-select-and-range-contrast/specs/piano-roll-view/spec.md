# Spec Delta：钢琴窗音域配色

## Purpose

让音符灰度与背景高亮都跟随黄色音域框，并拉开框内外的底色差异。

## ADDED Requirements

### Requirement: 音符灰色跟随音域框

音符颜色 SHALL 由音高是否处于黄色框体范围（上下各扩展 1 个半音）决定：框内使用正常颜色，超出上界或下界的音符显示为灰色。音域框拖动或键位映射变化时 MUST 立即刷新音符颜色。

#### Scenario: 框外音符变灰

- **WHEN** 把音域框上界降到某音符以下
- **THEN** 该音符立即变为灰色

#### Scenario: 框内恢复颜色

- **WHEN** 把音域框重新覆盖该音符
- **THEN** 音符恢复绿色（未选中时）

### Requirement: 框内外背景对比

背景淡色区域与框外深色区域 SHALL 有明显亮度差异，使用户无需细看即可辨认音域边界。

#### Scenario: 默认范围

- **WHEN** 打开曲目且音域框为默认 C2–B5
- **THEN** 框内行与框外行的底色亮度差异清晰可辨
