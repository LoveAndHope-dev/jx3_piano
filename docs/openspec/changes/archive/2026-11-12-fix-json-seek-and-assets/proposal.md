# play_code JSON 与播放辅助线同步

## Why

恢复 play_code JSON 播放后发现：JSON 里按键序列的时间原点被裁掉了开头静音（从第一个音符开始计时），而播放辅助线用的是整首曲子的绝对时间。于是从辅助线位置开始播放时，跳过量按绝对时间计算，会多跳掉一段，出现「点了播放却几乎没声音」或与辅助线不同步。

## What Changes

- play_code JSON 的 `playback_data` 起点对齐到 0 秒：生成时若第一个可播放音符不在 0 秒，先写入对应时长的延迟。
- 播放时按辅助线绝对时间裁掉之前的数据即可，辅助线从辅助线位置 + 已播放时长推进，实现钢琴窗任意位置开始播放。
- 保留既有行为：编辑→演奏或导入时自动保存 `midi/edited/<曲目>.mid` 与 `play_code/<曲目>.json`；删除曲目时一并删除。
- 吞音防护：保存时提示映射框外音符数量；生成按键时沿用 ±1 半音边界扩展，不静默丢弃框内音符。
- 效率：播放直接读取 JSON 并只做一次线性跳过，不重复做音符→按键转换。

## Impact

- `play_assets.py`：生成数据时补齐前导静音；新增时间原点字段。
- `gui.py`：辅助线起点改为「辅助线位置」，播放进度直接叠加；测试覆盖任意位置起播。
- `player.py`：继续使用 `start_at` 裁剪播放数据（已实现，补充验证）。
