# piano-roll-editing-modes Specification

## Purpose
提供「演奏 / 编辑」两种模式：演奏模式显示映射框并锁定铺面，编辑模式恢复全部编辑能力。

## Requirements

### Requirement: 演奏模式与编辑模式切换

工具栏 SHALL 提供「🎹 演奏模式 / ✏️ 编辑模式」切换按钮。演奏模式 MUST 显示黄色映射框、把铺面切换为只读，并启用「弹奏」按钮；编辑模式 MUST 隐藏映射框、恢复编辑，并禁用「弹奏」按钮。按钮文案 MUST 反映「点击后会进入的模式」（编辑中显示「🎹 演奏模式」，演奏中显示「✏️ 编辑模式」）。

#### Scenario: 切到演奏模式

- **WHEN** 编辑模式下点击「🎹 演奏模式」
- **THEN** 黄色映射框出现，铺面进入只读，按钮文案变为「✏️ 编辑模式」，「弹奏」按钮变为可用

#### Scenario: 切回编辑模式

- **WHEN** 演奏模式下点击「✏️ 编辑模式」
- **THEN** 黄色映射框隐藏，铺面恢复可编辑，按钮文案变为「🎹 演奏模式」，「弹奏」按钮变为禁用

### Requirement: 演奏模式的可操作范围

演奏模式下，钢琴窗 SHALL 拒绝选择、拖动、新建、删除、粘贴与方向键编辑；顶部标尺点击/拖动定位播放辅助线、工具栏选项（含 BPM、量化、映射范围、播放/保存）MUST 保持可用。

#### Scenario: 演奏模式下点击音符

- **WHEN** 演奏模式下点击或拖动铺面中的音符
- **THEN** 音符不被选中、不移动，铺面数据不变

#### Scenario: 演奏模式下键盘

- **WHEN** 演奏模式下按 Delete、Ctrl+V 或方向键
- **THEN** 铺面与剪贴板都不发生变化

#### Scenario: 演奏模式下定位播放辅助线

- **WHEN** 演奏模式下点击顶部标尺
- **THEN** 播放辅助线移动到点击位置，可继续播放
