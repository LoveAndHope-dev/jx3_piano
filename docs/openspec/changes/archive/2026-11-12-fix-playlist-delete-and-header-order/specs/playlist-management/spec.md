# Spec Delta

## ADDED Requirements

### Requirement: 播放列表项只显示一次曲目名

播放列表每个条目 SHALL 只显示一次曲目名，不得同时出现条目文字与行控件文字导致的叠影。搜索、排序与选中恢复 MUST 继续按文件名工作。

#### Scenario: 导入后显示正常

- **WHEN** 导入或新建一首曲目后查看播放列表
- **THEN** 每行曲目名只出现一次，没有重影

## MODIFIED Requirements

### Requirement: 从列表移除曲目并清理缓存

播放列表的每一行曲目末尾 SHALL 提供「🗑」删除按钮；点击并确认后 MUST 删除 `midi/` 目录下该曲目的副本文件（用户导入时选择的源文件不受影响），随后从列表移除并清空铺面音符、播放辅助线、BPM 与播放相关缓存（若删除的是当前曲目）。取消确认时 MUST 不删除文件、不改变列表与缓存。

#### Scenario: 移除未加载的曲目

- **WHEN** 点击某个未加载曲目行末的「🗑」并确认
- **THEN** `midi/` 中该副本被删除并从列表消失，当前铺面与播放状态不变

#### Scenario: 移除当前加载的曲目

- **WHEN** 点击当前正在编辑曲目行末的「🗑」并确认
- **THEN** 副本文件被删除，铺面清空、播放辅助线回到 0、BPM 重置、未保存标记清除、保存按钮禁用

#### Scenario: 取消删除

- **WHEN** 在确认框中点击取消
- **THEN** 文件、列表与缓存都不发生变化

#### Scenario: 刷新或重启后仍移除

- **WHEN** 删除后刷新列表或重启程序
- **THEN** 被删除的曲目不再出现

## REMOVED Requirements

### Requirement: 恢复被移除的曲目

**Reason**: 删除改为直接删除 `midi/` 副本，不存在可恢复的隐藏记录。

**Migration**: 需要找回时重新导入原始 MIDI 文件。
