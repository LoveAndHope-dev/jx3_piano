# 播放列表勾选框与使用向导

## Why

- 当前多选依赖 Ctrl/Shift 点击行，容易与“切换当前曲目”的操作混淆；用户希望勾选和选中明确分开：点行只切换当前曲目，勾选只用于批量删除。
- 功能都堆在界面里，缺少集中说明；新用户不清楚每个区域和快捷键的用途。

## What Changes

- **每行前置勾选框**：播放列表每行左侧增加复选框；点击行本身仍是单选（并加载该曲目），不会产生多选状态；只有点击复选框才累计批量选择。
- 「全选」改为勾选当前列表全部行；「删除选中」只删除被勾选的曲目。
- 刷新/搜索后保留仍然存在的勾选状态。
- **使用向导**：控制面板新增「❓ 向导」按钮，打开可滚动说明窗口，分节介绍：
  - 控制面板（导入/新建/刷新/置顶/亮暗切换）
  - 播放列表（选择、勾选、全选、删除、搜索排序）
  - 铺面编辑三行工具栏（模式切换、保存/演奏、曲谱优化、量化/BPM、键位与音域）
  - 钢琴窗（拖动/框选/缩放、Shift 纵向缩放、播放辅助线、黄框与配色）
  - 操作日志与快捷键（Ctrl+Z/Ctrl+Shift+Z、Ctrl+C/X/V、Shift+↑/↓ 等）
- 向导内容随界面实际行为编写，不引入外部链接。

## 非目标

- 不改变播放、编辑、曲谱优化与资产生成逻辑。
- 不改变列表排序、搜索与导入流程。
- 不增加首次启动自动弹窗（只在点击时打开）。
