# 乐器音域框（Instrument Range Box）

铺面编辑 Tab 中，覆盖当前显示曲目钢琴铺面（横向贯穿整个时间轴）的一个可拖动的黄色半透明覆盖层，加上「最低映射」「最高映射」两个下拉框。框体本身代表"演奏时要从当前铺面的原始音符里截取哪一段音高走向"（源音高选取窗口）；两个下拉框代表"实际演奏时允许使用的最低/最高按键"（目标按键范围）。两者互相解耦：框体只能通过拖动移动，下拉框只能通过下拉选择设置，任何一方的变化都不会回写到另一方。播放时，先用框体筛选原始音符，再把筛选出的音符按统一的移调量整体平移，最后复用既有的按键状态机映射为实际按键。

## 键位序列（ladder）

- 数据来源：以 `MidiToKeysConverter.base_note_mapping`（游戏 28 个固定按键，MIDI 36~83 的自然音，字母 `Z X C V B N M A S D F G H J Q W E R T Y U 1 2 3 4 5 6 7`）为基础，向下补齐 MIDI 21~35、向上补齐 MIDI 84~108 范围内的全部自然音（白键，即一个八度内相对偏移不在 `{1,3,6,8,10}` 的音高），得到一个覆盖 MIDI 21~108 全部自然音位置、按音高升序排列的序列（共约 52 项）。
- 标签：序列中原属于 `base_note_mapping` 的 28 个位置显示对应的游戏按键字母标签；其余新增位置显示标准音名（`{音名}{八度号}`，八度号 = `pitch // 12 - 1`，与铺面背景 C 音标签同一口径），例如 `A0`、`B0`、`C1`、`C8`。
- 该序列是「最低映射」「最高映射」下拉框选项、框体拖动吸附、以及框体跨度计算的唯一数据来源；黑键/半音位置不出现在序列中。

## 下拉框（目标按键范围）

- 「最低映射」「最高映射」两个下拉框的选项为上述键位序列（约 52 项），按音高升序排列。
- 默认选中项为序列中对应字母 `A`（MIDI 48）与 `J`（MIDI 59）的两项。
- 修改任一下拉框的值后：若新值使「最低」>「最高」，自动把另一侧下拉框同步到与之相等的值（保持最低 ≤ 最高的不变量）。
- 下拉框的值发生变化（且校验通过）后，按两者在键位序列中的位置差，重新计算框体的跨度（见下）；下拉框本身不再直接设置框体的低/高边界音高。
- 下拉框的值只由用户下拉选择改变，不随框体拖动而改变。

## 框体（源音高选取窗口）

- 框体自身维护一个独立的"低边界音高"状态，只能通过拖动改变。
- 框体的跨度（`span_idx`，按键位序列中的位置数计算，不按半音数）= 「最高映射」在键位序列中的位置 − 「最低映射」在键位序列中的位置；下拉框变化时立即按新的位置差重新计算框体跨度。
- 框体跨度重新计算时：保持框体当前低边界音高不变，只重新计算高边界（`高边界 = 键位序列[低边界在序列中的位置 + span_idx]`）；如果这样计算出的高边界会超出键位序列的最高项（对应铺面顶端 MIDI 108 附近），把低边界下压到刚好能使新跨度完整落在序列范围内的位置（`低边界在序列中的位置 = min(原位置, 序列长度 - 1 - span_idx)`），跨度本身不被截断——与拖动到边界时的钳制方式一致。
- 框体默认低边界为序列中对应字母 `A`（MIDI 48）的位置，默认跨度对应「最低映射」=`A`、「最高映射」=`J` 的位置差（即默认高边界为 `J`，MIDI 59），与下拉框默认值一致。

## 拖动交互

- 仅当框体可见，且鼠标在框体内部、非音符所在位置按下时，进入"平移框体"拖动模式。
- 拖动过程中，框体的低、高边界音高同步平移，平移跨度（按键位序列中的位置距离计算）保持不变；新的低/高位置吸附到键位序列中最接近目标音高的位置。
- 平移边界为整条键位序列的两端：可以一路平移到序列最低项（覆盖铺面最底端，MIDI 21 附近）或最高项（覆盖铺面最顶端，MIDI 108 附近）。
- 拖动过程中每次位置变化都：更新框体内部的低/高边界音高状态、重新绘制框体几何；拖动不会读取或改变「最低映射」「最高映射」两个下拉框的当前显示值。
- 不支持通过拖动框体边缘单独调整跨度；调整跨度只能通过两个下拉框的差值。

## 可见性

- 「显示/隐藏映射」按钮切换框体在铺面中的可见性，纯视觉开关：不可见时不绘制黄色框体，但框体当前的低边界/跨度、以及两个下拉框的当前值，仍然是播放时使用的依据，不受可见性影响。
- 每次在播放列表中选中（或重新选中）一首曲目时，框体位置（低边界 + 跨度）与两个下拉框都重置为默认值（对应字母 `A`~`J`，MIDI 48~59），可见性重置为隐藏；同一首曲目保持选中期间对框体位置/下拉框/可见性的调整会保留，直到切换到其他曲目。

## 播放：筛选 → 移调 → 按键映射

点击播放时，基于当前铺面上显示的音符（含铺面编辑的当前状态）、框体当前范围与两个下拉框当前值，按以下三步在内存中生成按键序列：

1. **筛选（源端，按原始音高）**：框体的实际筛选范围 = `[框体当前低边界音高 - 1, 框体当前高边界音高 + 1]`（半音，MIDI 值，按半音而非序列相邻标签计算）。只有原始音高落在这个范围内的音符被选中，其余音符被静默跳过，不参与后续步骤。
2. **移调（统一整体平移）**：移调量 = 「最低映射」当前对应音高 − 框体当前低边界音高（只用「最低映射」作锚点，「最高映射」的绝对音高不直接参与这一步计算）。所有被选中的音符按这个移调量整体平移（`播放音高 = 原始音高 + 移调量`），音符之间原有的音程关系保持不变，不做任何按比例拉伸或压缩。
3. **按键映射（复用既有状态机）**：对每个移调后的播放音高，复用 `MidiToKeysConverter.midi_note_to_key_sequence` 现有的音高 → 按键状态机逻辑生成按键序列；该状态机的既有行为不变——落在游戏 28 键实际映射表（`base_note_mapping`/`sharp_notes`/对应降号推导，约 MIDI 35~84）之外的播放音高，状态机返回空按键列表，这些音符被静默跳过，不报错。状态机的"半音"处理（升/降号临时切换、下一个自然音符时复原）沿用既有实现：这里的"半音"专指框体或按键序列边界处、无法直接用某个自然键按出、只能通过游戏内"+"（升半音特殊功能键）/"-"（降半音特殊功能键）临时切换、演奏完当前这一个音符后立刻复原的音符，不等同于笼统的"黑键"。

若筛选、移调、按键映射三步之后没有任何可播放音符，弹出既有的"当前乐器音域范围内没有可播放的音符"提示，不触发实际播放。播放数据全程在内存中生成，不写入 `play_code/` 或任何磁盘文件。
