# 设计探索摘要（Design）

change: `piano-roll-modes-and-daw-editing`

## 已确认（用户）

- 「显示/隐藏映射」改为「演奏模式/编辑模式」；演奏模式铺面只读，工具栏与播放辅助线可用。
- Shift+滚轮缩放改为 Ctrl+滚轮。
- 按钮高度与下拉框一致；页脚文字更新。
- 钢琴窗编辑逻辑对齐主流 DAW（基线已在 Open 产物中列明并确认）。

## 现状事实

- `gui.on_range_toggle_clicked` 只切换黄框可见性。
- `_PianoRollCanvas._read_only` 已覆盖鼠标/键盘编辑入口，播放期间使用。
- 空白区域按下进入 `select-rect-or-create`：拖动框选、不拖动则松开新建。
- 只有右边缘 6px 可调整时长；无左边缘、无普通方向键。
- `wheelEvent` 用 Shift 触发缩放。
- 按钮高度由全局 QSS 决定，高于下拉框。

## 候选方案

1. 模式复用 `_read_only`：演奏模式 = 黄框可见 + 只读；编辑模式 = 黄框隐藏 + 解除只读（播放中除外）。
2. 标尺定位与只读解耦：新增 `set_playhead_locked`，播放期间锁定，模式不影响辅助线定位。
3. 空白手势：单击清空、双击新建（`mouseDoubleClickEvent`）、拖动框选。
4. 左边缘：命中判定新增 `resize-start` 模式，结束时间不变并钳制最小时长。
5. 方向键：←/→ 步长取量化网格（关闭时 0.1s），↑/↓ 半音，Shift+↑/↓ 八度。
6. Ctrl+滚轮替换 Shift。
7. QSS 统一按钮高度 26px；页脚文案更新。

## 备选与丢弃

| 备选 | 原因 |
| --- | --- |
| 新增独立 `mode` 字段 | 与 `_read_only` 重复，两套开关易漂移 |
| 用单击延迟定时器区分双击 | 增加输入延迟，且 Qt 已提供双击事件 |
| 左边缘与右边缘同时命中时按距离取近 | 短音符会抖动；固定优先右边缘更稳定 |

## 风险

- 播放中切回编辑模式不得解除只读 → 用 `is_playing` 决定。
- 双击前会先触发一次 press/release，单击清空可能造成瞬间闪烁 → 双击路径先创建并选中。
- 短音符左右命中重叠 → 优先右边缘。
